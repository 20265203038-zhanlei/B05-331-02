## 二、GitHub 怎么在库里写评论

### 🧑 用户
GitHub 怎么在库里写评论?

### 🤖 助手

**1. Issue(议题)评论:** 打开仓库 → Issues → 选择议题 → 底部评论框输入 → Comment 提交。

**2. Pull Request(PR)评论:** 打开仓库 → Pull requests → 选择 PR → 底部 Conversation 标签页评论框输入并提交;审查代码可进 Files changed 页面。

**3. 代码行内评论(PR 审查):** PR 的 Files changed 页面 → 悬停目标代码行点蓝色 + 号 → 输入评论。可选 Add single comment(单独发表)或 Start a review(累积后统一提交,支持 Approve / Request changes / Comment)。注意:只有 PR 的 diff 页面才能对代码行评论。

**4. Commit 评论:** 打开某次 commit,diff 行上悬停点 + 号写行级评论,或底部评论框写整体评论。

**5. Discussions 评论:** 若仓库开启 Discussions:仓库 → Discussions 标签 → 进入帖子 → 底部回复。

**评论框技巧:** 支持 Markdown(@用户名 可提醒对方;# 可引用 Issue/PR;提交后可 Edit 或 Delete)。

## 三、md 是什么文件格式

### 🧑 用户
# md 是什么文件格式

### 🤖 助手

**.md 是 Markdown 文件**,一种纯文本格式的标记语言文件,用简单符号给文字加排版效果。

- 本质是纯文本,记事本即可打开编辑
- 靠符号排版,渲染后变成标题、列表、链接、表格等
- GitHub、知乎、语雀、Notion、Obsidian 等平台均支持

**常用语法:**

| 写法 | 效果 |
|---|---|
| `# 标题` | 一级标题(## 二级,以此类推) |
| `**加粗**` | 加粗 |
| `*斜体*` | 斜体 |
| `[链接](url)` | 超链接 |
| `![图片](地址)` | 插入图片 |
| `- 项目` | 无序列表 |
| `` `代码` `` | 行内代码 |
| `> 引用` | 引用块 |
| `---` | 分隔线 |

**常见场景:** GitHub 的 README.md、技术文档/博客、笔记软件(Typora、Obsidian 等)。

**打开方式:** 记事本/VS Code 直接打开;Typora 等专用编辑器;GitHub 自动渲染;VS Code 中 Ctrl+Shift+V 预览。

**一句话总结:md = 带轻量排版标记的纯文本文件,是程序员和技术写作者最常用的文档格式。**

## 四、Zotero 可以把外文文献翻译成中文吗

### 🧑 用户
Zotero 可以把外文文献翻译成中文吗?

### 🤖 助手

官方版 Zotero 本身没有翻译功能,需要装插件或搭配其他工具:

**方案一:安装翻译插件(最主流)**
- 国内流行的 Zotero 中文社区版已内置翻译插件;官方原版可手动装 Translate for Zotero(windingwind 出品)
- 功能:标题/摘要自动翻译、PDF 划词翻译、整段/全文翻译、笔记翻译

**方案二:外部翻译工具**
- 知云文献翻译:专为读文献设计,PDF 左右分栏对照,免费
- 小绿鲸英文文献阅读器:文献管理 + 全文对照翻译
- 沉浸式翻译浏览器插件:网页版文献双语对照
- DeepL / 有道 / ChatGPT:复制段落翻译

**方案三:AI 辅助精读:** 把 PDF 喂给支持文献的 AI 工具,可翻译 + 逐段讲解 + 总结。

**提醒:**
1. 专业术语建议保留英文原词,避免机翻歧义
2. 没有完美的整篇自动翻译插件,通读全文推荐知云或沉浸式翻译
3. 译文仅自用,注意版权

**推荐组合:** Zotero + Translate for Zotero(标题摘要秒翻)+ 知云文献翻译(全文对照精读)。

## 五、翻译插件安装方法

### 🧑 用户
怎么安装翻译插件呢?

### 🤖 助手

以 Translate for Zotero 插件为例:

**第一步:下载插件文件**
1. 打开发布页:github.com/windingwind/zotero-pdf-translate/releases
2. 最新版本 Assets 里下载 .xpi 文件(注意认准 Zotero 7 专用版本,Zotero 6 要下对应版本)
3. 不用解压,保留 .xpi 原文件
- 省事方案:直接安装 Zotero 中文社区版(官方版 + 汉化 + 预装常用插件)

**第二步:在 Zotero 中安装**
1. 打开 Zotero → 工具(Tools)→ 插件(Plugins)
2. 点右上角齿轮图标 → Install Plugin From File...
3. 选中下载的 .xpi 文件 → 确认安装 → 重启 Zotero

**第三步:配置翻译服务**
- 编辑 → 设置 → 翻译 选项卡
- 可选服务:Google 翻译(免 Key,国内网络可能不稳)、百度/火山/腾讯翻译(需申请免费 API Key)、DeepL(质量好,免费有额度)
- 按需勾选"自动翻译条目标题和摘要"

**第四步:开始使用**
- 翻译标题/摘要:点击文献,右侧面板自动显示中文
- PDF 划词翻译:打开 PDF,选中句子即弹出翻译
- 整段翻译:选中一整段,结果以注释插入

**常见问题:**
- 装完没反应 → 检查插件与 Zotero 版本匹配,重启
- 翻译失败/超时 → 换翻译服务或配置代理
- 菜单英文 → 装汉化包或用中文社区版
- 不要装多个功能重复的翻译插件
